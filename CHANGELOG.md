# Changelog

## v1.0.0 — First public release

**Download:** `HID-Remote-v1.0.0.apk` (2.3 MB · Android 9+)

### ✨ Highlights
- **Air mouse** — wave your phone like a laser pointer; the gyroscope moves the cursor. Tap the pad to click. Adjustable speed in Settings.
- **Snippets** — save phrases you type often (emails, addresses, commands) and send them with one tap from the keyboard's *Type* tab.
- **Welcome screen** — a first-run guide that explains the app and sets up the Bluetooth permission.
- **About & links** — author credit, source code, update check, bug reports and one-tap sharing.

### 🖱️ Everything else in the box
- Precision touchpad: velocity-based acceleration, tap / two-finger / three-finger clicks, momentum scrolling, tap-and-drag, drag lock, three-finger swipes.
- Compact keyboard (Keys, Fn, Shortcuts, Type tabs) and a full landscape keyboard with an optional side touchpad.
- Sticky modifiers (tap = one-shot, long-press = lock), live typing with IME corrections, type-the-clipboard.
- Media & TV remote: D-pad, Home/Back/Menu, volume, playback, brightness and a presentation clicker.
- Shortcuts that adapt to Windows, macOS, Linux and Android TV.
- Auto-reconnect, six accent colours, pure-black AMOLED mode, left-handed buttons, haptics.

### 🔒 Privacy & size
- Removed every unused library inherited from the project template (Firebase, Room, Retrofit, OkHttp, Moshi). The app **no longer requests the INTERNET permission**.
- R8 code + resource shrinking: the APK is **2.3 MB**.
